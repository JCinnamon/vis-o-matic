Powerful image analysis, right in your browser.

Vis-O-Matic is a free suite of tools for working with image datasets. Organise and curate them in Image Manager, cut regions out with Image Cutter, measure colour with the Batch Image Analyzer, plot the results in Image Visualizer, and register 360° frames to true north with SunSync 360. Group your work into a project and it carries across all five.

Runs in the browserNothing uploadedNo installationNo accountFree and open source
The tools
Image ManagerHold, curate and organise your image datasets. Image CutterCut any region out of an image with a segmentation model. Batch Image AnalyzerMeasure colour across a whole set at once. Image VisualizerPlot colour values as strips, grids, scatters and wheels. SunSync 360Register 360° frames to true north using the sun.

A project keeps one body of work together — the image datasets, everything the tools produce from them, and a record of what was run. Start one here, then open it in any tool.

Every dataset you have, across all your projects. A dataset is not copied into a project — it is referenced, so one set can belong to several without taking the space twice. Tick a project to file it there.
